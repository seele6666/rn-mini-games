流程见 [记忆技能](../.agents/skills/project-memory/SKILL.md)；委派见 [子代理技能](../.agents/skills/project-delegation/SKILL.md)。

## 查找与来源

- [长期要求与替代记录](preferences.md)：按编号或适用范围查找，只应用有效且相关的条目。
- [候选记忆](candidates.md)：待观察内容；晋升后迁移，避免重复。
- 当前用户要求优先于旧记忆；临时例外只作用于当前任务。
- 正式游戏行为见 `openspec/specs/`；任务状态见对应变更的 `tasks.md`，不复制到记忆中。
- 规划、只读或写入受阻时，待沉淀内容尚未落盘，应明确说明。
- 本索引保持约30行；增长时按范围分组并保留完整查找入口。
