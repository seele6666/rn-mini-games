# 项目长期要求

只应用状态为“有效”且适用范围匹配的条目。以下来源均为 2026-10-11 用户本轮明确要求实施的计划，不统计举例或助手复述。

## M-001：每轮展示规范评估

- 规则：每个用户轮次开场展示两条简短勾选，分别说明记忆是否适用、是否需要子代理。勾选表示完成评估，后续进度更新无需重复展示。
- 适用范围：本项目所有用户轮次，由主代理展示。
- 状态：有效
- 来源：
  - 2026-10-11，本轮用户批准实施的计划第4节：“每轮开始展示两条简短勾选”。
- 出现次数：1

## M-002：自动沉淀长期要求与重复偏好

- 规则：明确长期要求立即记录；同一偏好在两个不同用户轮次出现后自动沉淀。临时要求、举例、引用材料和助手表述不作为长期偏好证据。
- 适用范围：本项目记忆维护；写入遵守当前模式和权限。
- 状态：有效
- 来源：
  - 2026-10-11，本轮用户批准实施的计划第3节：“明确的长期要求立即记录。”“同一偏好在两个不同用户轮次出现后自动沉淀。”
- 出现次数：1

## M-003：记忆内容与技能流程分别维护

- 规则：自动更新记忆内容；技能流程仅在用户明确提出改进要求时调整，并验证调整结果。
- 适用范围：本项目记忆与技能维护。
- 状态：有效
- 来源：
  - 2026-10-11，本轮用户批准实施的计划第3节：“自动更新记忆内容；技能流程仅在你明确提出改进要求时调整。”
- 出现次数：1
