## 查找与来源

- [长期要求与替代记录](preferences.md)：只应用有效且范围匹配的条目。
- [候选记忆](candidates.md)：待观察条目，晋升后迁移，避免重复。
- 当前用户明确要求优先；临时例外仅作用于当前任务。
- 正式行为以项目规格为准，任务进度以相应 `tasks.md` 为准，不复制到记忆。
- 自动写入需要当前项目用户授权，并遵守当前模式和权限；受阻时说明尚未落盘。
- 索引保持约30行，增长时按范围分组并保留查找入口。
