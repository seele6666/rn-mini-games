# Superpowers 入口

本目录只作导航；实际插件技能以当前 Codex 会话技能列表为准，不复制插件缓存、不固定版本路径。

常用技能：`superpowers:brainstorming`、`superpowers:writing-plans`、`superpowers:test-driven-development`、`superpowers:systematic-debugging`、`superpowers:requesting-code-review`、`superpowers:verification-before-completion`。

缺少插件时，按当前环境支持的插件管理入口安装 Superpowers，再核实技能是否出现；仅存在本文档不代表安装成功。

OpenSpec 管变更文档和任务进度，Superpowers 提供相应任务的方法。按照当前用户授权和适用技能执行，不建立相互矛盾的审批或第二套任务进度。
