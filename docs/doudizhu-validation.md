## 可复现策略基准

运行器：`src/features/doudizhu/ai/benchmark.test.ts`。普通 Jest 仅运行单局运行器校验，跳过长测。PowerShell 执行完整基准：

```powershell
$env:DOUDIZHU_BENCHMARK = '1'
Remove-Item Env:DOUDIZHU_BENCHMARK_SEEDS -ErrorAction SilentlyContinue
npm test -- --runInBand src/features/doudizhu/ai/benchmark.test.ts --cacheDirectory verification/doudizhu/benchmark-jest-cache
Remove-Item Env:DOUDIZHU_BENCHMARK -ErrorAction SilentlyContinue
```

可临时设置 `$env:DOUDIZHU_BENCHMARK_SEEDS = '4'` 测量吞吐；少于100种子不作为完整验收。JSON 先落盘再断言，因此排名失败、非法动作、异常和未结束种子仍保留。报告路径：`verification/doudizhu/benchmark-100-seeds.json`；短测为 `benchmark-4-seeds.json`。

方法：固定整数种子1至100，真正洗发17/17/17＋3张牌；固定座位0起叫，经叫、不抢、不抢进入地主0的出牌阶段。每个种子轮换目标策略所在座位0（地主）、1（地主下家农民）、2（地主上家农民）；只有目标座位分别替换为简单、普通、困难，其余两座位固定普通。对照共享同牌同角色，普通基线复用，共900实际局、两个各300对配对对照。地主／农民胜负按目标座位是否属于 `winner.seats` 统计，分角色及总体记录双赢、双输、改善、退步和未完成数。叫抢能力由独立规则和策略测试覆盖。

每一步策略仅接收 `buildObservation` 产生的自身可见输入。洗牌随机源和按种子／座位／revision派生的策略随机源独立，不共享消耗。困难使用真实 `chooseHardAction`，关闭预先生成合法动作列表，固定节点400、工作量20000、时间参数150ms，测试时钟恒0、让出函数为异步空函数。固定时钟使比较由节点／工作预算决定；真实 `performance.now()` 另行记录每次困难决策和整局墙钟。手机实际调度使用真实时钟与让出线程，不能以本基准替代设备性能。

每局1000步上限；报告记录非法动作、异常、未终局、困难搜索状态、采样数、模拟节点、工作量及墙钟p50／p95／最大值，并记录 Node、Jest、操作系统、CPU及策略文件 SHA-256。验收目标：所有局合法结束，普通总体胜率高于简单，困难总体胜率不低于普通；胜率仅代表这组固定样本和预算。

4种子冒烟：36局耗时19.27s，简单9/12、普通7/12、困难10/12；非法／异常／未终局均0。普通优于简单的断言失败，已保留实际结果。

### 本地构建与产物核验

```powershell
.\gradlew.bat :app:assembleRelease -PreactNativeArchitectures=arm64-v8a --max-workers=2 --no-daemon --offline -x lintVitalAnalyzeRelease -x lintVitalReportRelease -x lintVitalRelease --console=plain
```

## 困难档与返回的取数方法

用同一独立APK、正常设备负载，记录冷启动／预热状态、温度、刷新率和后台应用。每次困难决策从开始计算到结果返回记录单调时钟毫秒，包含候选生成、评分、采样、模拟和实际让出线程的等待。至少采集100次困难决策，覆盖地主20张、两种农民座次、领出与跟牌；保留全部样本以及搜索节点、状态、是否取消，不只保留完成快的样本。对耗时排序，最近秩法取第 `ceil(0.95*N)` 个样本为p95，目标≤500ms，同时报告样本数、p50和最大值。

返回测试至少30次，覆盖困难计算的候选生成、采样和推演期间，页内返回与Android系统返回分别记录。用原生输入事件时间戳和首个显示首页的帧时间戳计算响应；可使用Perfetto／Android帧trace配合事件记录，或高帧率外部录像逐帧计数并报告量化误差（60fps一帧约16.7ms）。输入确认、路由处理和画面呈现都包含在响应里，不能仅计回调执行时间。正常负载下目标≤100ms，逐次列出并报告p95／最大值；越限保留失败样本和trace。

这些取数尚未执行。Node墙钟、Web浏览器录像、Jest模拟计时和Android导出成功均不足以证明原生响应或离线独立APK验收通过。
