# Brainstorm

## Goal and audience

为自己制作一个可以长期玩的 Android 小游戏集合，同时把它作为 React Native 学习作品。应用打开后进入游戏选择首页；首版只有 2048，今后可以增加其他小游戏。最终交付可独立安装的 APK。

## Known constraints

- 使用 React Native 和 Expo，目标平台为 Android。
- 首版只有经典 2048；关闭应用后再次打开，要恢复上次进度。
- 合成 2048 后提示成功，但可以继续挑战 4096 或更高数字。
- 当前项目只有 OpenSpec 工作目录，没有 RN 工程、游戏代码、现有产品规格或进行中的变更。

## Options considered

- Expo 与直接维护 Android 原生工程：用户选择 Expo，便于先学习 RN 页面、状态和手势。
- 只在 Expo Go 中运行与生成独立 APK：用户选择独立 APK 作为最终交付物。
- 首版实现多个小游戏与只实现 2048：用户选择先做 2048，首页保留未来添加游戏的入口形态。

## Confirmed decisions

- 首页可选择小游戏；首版仅有 2048。
- 2048 使用经典玩法，保留上次进度；到达 2048 后可继续玩。
- 使用 Expo，交付独立 Android APK。

## Working assumptions

- 首版只显示可玩的 2048 入口，不放虚构的游戏卡片。
- 4×4 棋盘、分数、游戏结束、重新开始遵循常见 2048 行为；胜利后继续模式不改变棋盘大小或目标提示的含义。
- 游戏数据只保存在当前设备；无需账户、联网、排行榜、音效、自定义棋盘或撤销。
- 先用 Expo Go 调试，安装包使用 EAS Build 的 APK 配置生成；如果用户希望完全本地构建，再调整设计。

## Open questions

没有会改变首版范围的未决问题。应用名称、图标视觉和 APK 构建账号可在实施前按默认方案确认或调整。
