# Implementation Note: 5.1 APK 构建配置

**Task:** 5.1 in ../tasks.md

## Requirement and dependencies

对应 `../specs/android-installation/spec.md` 的“提供可安装 APK”。依赖任务 1.1 到 4.2 的可运行应用。

## Files and interfaces

- `app.json`：应用显示名“小游戏合集”、稳定的 Android 包名 `com.seele.minigames`。
- `eas.json`：增加 `preview` 构建档，设置 `android.buildType: "apk"`。
- 更新根目录 `README.md`：开发运行、测试、构建 APK、下载安装与断网验收步骤；保留既有 OpenSpec 使用说明。

## Steps

1. 配置应用显示名、标识与 APK 构建档；核对 Expo 当前版本与 EAS CLI 支持的配置格式。
2. 写明构建需要 Expo 登录和联网，构建命令为 `eas build -p android --profile preview`；说明产物链接或下载位置，以及安装步骤。
3. 在构建前运行完整 TypeScript、Jest 和 OpenSpec 校验，修复阻断问题。

## Verification

运行 `npx tsc --noEmit`、`npm test -- --runInBand`、`openspec validate add-game-hub-2048 --strict`。检查 `eas.json` 的 preview Android 构建类型明确为 `apk`，README 中的命令与配置一致。

## Risks or handoff notes

EAS 默认 Android 构建常为 AAB；必须显式设置 APK。若包名与已有个人应用冲突，首次构建前改成新的稳定包名并同步说明。
