# Implementation Note: 2.2 胜利与结束判定

**Task:** 2.2 in ../tasks.md

## Requirement and dependencies

对应 `../specs/classic-2048/spec.md` 的“达到目标后继续游戏”和“检测游戏结束”。依赖任务 2.1 的规则引擎。

## Files and interfaces

- 扩展 `src/features/game2048/engine.ts` 中的 `moveGame`、`canMove`，沿用任务 2.1 的返回类型；`GameState.hasWon` 表示本局已经提示过首次达到 2048。
- 扩展 `src/features/game2048/engine.test.ts`，覆盖目标和终局边界。

## Steps

1. 先写测试：第一次合并出 2048 时 `reached2048` 为真；继续游戏后再次合出 2048 不再触发；合出 4096 继续计分。
2. 为满盘但仍有相邻相同值、满盘且完全不能合并分别写测试。实现 `canMove` 检查空格和水平、垂直相邻方块。
3. 在有效移动并生成新方块后计算 `gameOver`；无效移动不得改变棋盘、分数和胜利状态。

## Verification

运行 `npm test -- --runInBand src/features/game2048/engine.test.ts` 与 `npx tsc --noEmit`。预期所有胜利、继续、4096 和两种满盘状态测试通过。

## Risks or handoff notes

`hasWon` 记录“首次提示已发生”，不表示游戏必须停止。游戏结束从棋盘推导，无需另存一个易失真的标记。
