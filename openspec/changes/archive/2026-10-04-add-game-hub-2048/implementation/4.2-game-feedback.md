# Implementation Note: 4.2 胜利、结束与重新开始交互

**Task:** 4.2 in ../tasks.md

## Requirement and dependencies

对应 `../specs/classic-2048/spec.md` 的“达到目标后继续游戏”“检测游戏结束”和 `../specs/game-catalog/spec.md` 的“进入和离开 2048”。依赖任务 4.1。

## Files and interfaces

- 修改 `src/app/games/2048.tsx`：胜利提示、继续按钮、结束提示和重新开始按钮。
- 复用 `useGame2048()` 提供的 `winVisible`、`gameOver`、`restart()` 与 `continueAfterWin()`；返回首页使用 Expo Router。

## Steps

1. 首次达到 2048 时展示提示与“继续挑战”操作；继续后保留棋盘并允许合成 4096 及更大数字。
2. 无路可走时展示结束状态和重新开始入口；有合并机会的满盘不能误报结束。
3. 点击重新开始先确认，再生成 0 分新局并保存；Android 返回键回首页，再进入时恢复原局或新局。

## Verification

在 Android 上手动复核首达 2048、继续、游戏结束、取消与确认重新开始、返回首页再进入。预期胜利提示每局只出现一次，重新开始后恢复的是新局。

## Risks or handoff notes

胜利提示与游戏结束可能在同一局先后发生。继续后的终局仍按正常结束逻辑处理。
