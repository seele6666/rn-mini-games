# Spec Delta

## Purpose

小游戏选择首页让玩家从一个稳定的入口找到并打开已提供的游戏。首版只展示可以实际游玩的 2048，之后增加其他小游戏时沿用同一选择方式。

## ADDED Requirements

### Requirement: 启动进入小游戏首页

应用 SHALL 在正常启动后展示小游戏选择首页。

#### Scenario: 首次打开应用

- **WHEN** 玩家打开应用
- **THEN** 首页展示 2048 游戏入口
- **THEN** 首页不展示尚未实现的游戏为可玩入口

### Requirement: 进入和离开 2048

玩家 SHALL 能从首页进入 2048，并返回首页。

#### Scenario: 选择 2048

- **WHEN** 玩家点击首页的 2048 入口
- **THEN** 应用展示 2048 游戏界面

#### Scenario: 返回首页

- **WHEN** 玩家在游戏界面使用返回操作
- **THEN** 应用展示小游戏首页
- **THEN** 当前棋盘留待下次进入时恢复
