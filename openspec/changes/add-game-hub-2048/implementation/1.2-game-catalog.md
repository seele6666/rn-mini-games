# Implementation Note: 1.2 首页与游戏入口

**Task:** 1.2 in ../tasks.md

## Requirement and dependencies

对应 `../specs/game-catalog/spec.md` 的“启动进入小游戏首页”和“进入和离开 2048”。依赖任务 1.1 的 Expo Router 工程。

## Files and interfaces

- `src/app/_layout.tsx`：简单 Stack 导航，首页为初始路由。
- `src/app/index.tsx`：小游戏首页，仅渲染 2048 入口。
- `src/app/games/2048.tsx`：本任务先提供可导航的游戏页占位，后续任务替换为棋盘。
- 可选 `src/features/catalog/games.ts`：静态游戏定义 `{ id: '2048', title: '2048', href: '/games/2048' }`，后续新增游戏时再追加条目。

## Steps

1. 移除 Expo 模板的演示路由、底部栏与不再使用的演示组件，将首页改成单个可访问的 2048 卡片。
2. 实现首页点击进入 2048 路由，游戏页使用导航返回操作回首页；为卡片添加可读的无障碍标签。
3. 在 Android 开发运行环境检查两个路由及 Android 返回键。若加入组件测试，验证首页只有一个可玩入口。

## Verification

运行 `npx tsc --noEmit`。在 Android 上启动应用，预期首先看到首页，点击 2048 进入游戏页，再返回首页；首页没有未实现游戏的可玩卡片。

## Risks or handoff notes

本任务中的 2048 页面只是导航落点；棋盘和玩法分别由后续任务完成。
