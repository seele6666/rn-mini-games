# Implementation Note: 2.1 棋盘和移动规则

**Task:** 2.1 in ../tasks.md

## Requirement and dependencies

对应 `../specs/classic-2048/spec.md` 的“创建经典棋盘”与“按方向移动和合并”。依赖任务 1.1 的 TypeScript 与 Jest 环境。

## Files and interfaces

- `src/features/game2048/engine.ts`：导出 `Direction = 'up' | 'down' | 'left' | 'right'`、`Board = number[][]`、`GameState = { board: Board; score: number; hasWon: boolean }`。
- 导出 `createGame(random?: () => number): GameState`、`moveGame(state: GameState, direction: Direction, random?: () => number): { state: GameState; moved: boolean; reached2048: boolean; gameOver: boolean }`、`canMove(board: Board): boolean`。
- `src/features/game2048/engine.test.ts`：只测试纯函数；用可控随机数固定新方块位置和值。

## Steps

1. 先为创建棋盘、生成 2/4、四方向滑动、单次合并与无效移动编写失败测试。
2. 实现每行压紧和成对合并；右/上/下通过坐标变换复用同一套行规则。每步先比较移动前后棋盘，只有变化时才生成新方块。得分增加所有新合并方块的值。
3. 新棋盘在不同空格生成两块；随机值默认 90% 为 2、10% 为 4。避免原地修改传入的棋盘。

## Verification

运行 `npm test -- --runInBand src/features/game2048/engine.test.ts`。预期覆盖 `2 2 2 2` 向左变成 `4 4` 且加 8 分、四方向移动、无效移动不生成方块，以及两块初始方块互不重叠。

## Risks or handoff notes

本任务只建立引擎和单测，不接入 UI。对新方块的位置和值使用随机数注入，以免测试依赖概率。
