# Implementation Note: 5.2 独立 APK 真机验收

**Task:** 5.2 in ../tasks.md

## Requirement and dependencies

对应 `../specs/android-installation/spec.md` 的“提供可安装 APK”和“独立运行核心游戏”。依赖任务 5.1 的配置与测试通过。

## Files and interfaces

- 读取 `eas.json` 和根目录 README 的构建说明。
- 如构建或真机问题暴露配置错误，再修改相关工程文件，并把修复后的步骤写回 README。APK 构建产物与构建链接作为验收证据记录。

## Steps

1. 登录个人 Expo 账号后运行 `eas build -p android --profile preview`，等待构建完成，下载 `.apk`。若构建服务要求项目关联或签名，按 Expo CLI 的交互提示完成个人项目配置。
2. 在自己的 Android 手机上安装 APK，关闭 Expo Go 与开发服务器，并断开网络。
3. 验证首页只有 2048 入口、滑动合并与计分、胜利后继续、重新开始、回首页再进入；关闭并重启应用，确认恢复最后状态。
4. 记录 APK 的文件位置或可访问的构建链接以及验证结果。若当前没有手机或构建账号，只记录已经完成的本地验证和具体阻碍，保留本任务未完成状态。

## Verification

取得可以安装的 `.apk`，在 Android 真机离线运行且通过上述完整手动流程；确认不依赖 Expo Go 或开发服务器。所有检查通过后才在 `tasks.md` 勾选本任务。

## Risks or handoff notes

此任务需要真实 Android 设备及可用的 Expo 构建账号。构建成功只能证明拿到了 APK，不能替代离线真机验收。
