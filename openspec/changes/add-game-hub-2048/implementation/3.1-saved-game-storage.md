# Implementation Note: 3.1 本地存档

**Task:** 3.1 in ../tasks.md

## Requirement and dependencies

对应 `../specs/saved-game/spec.md` 的“自动保存当前局”“安全恢复或新建游戏”和“重新开始覆盖当前存档”。依赖任务 2.1 的 `GameState` 类型。

## Files and interfaces

- `src/features/game2048/storage.ts`：导出 `loadGame(): Promise<GameState | null>` 与 `saveGame(state: GameState): Promise<void>`；存储键固定为 `game2048.save.v1`，内容为 `{ version: 1, state: GameState }`。
- 为测试提供可注入的 `getItem`、`setItem` 适配器，生产环境使用 `@react-native-async-storage/async-storage`。
- `src/features/game2048/storage.test.ts`：模拟存储读写、损坏数据和写入覆盖。

## Steps

1. 用 `npx expo install @react-native-async-storage/async-storage` 安装与 Expo 版本匹配的依赖。
2. 先写有效、缺失、损坏、旧版本与重新开始覆盖的测试；校验 4×4 格子只含 0 或 2 的幂、分数是非负整数、`hasWon` 是布尔值。
3. 实现读取和写入。读不到有效数据时返回 `null`，由状态层创建新局；写入错误向状态层抛出，以便显示提示。

## Verification

运行 `npm test -- --runInBand src/features/game2048/storage.test.ts` 与 `npx tsc --noEmit`。预期坏存档不崩溃，新的存档可读回相同棋盘、分数与胜利标记。

## Risks or handoff notes

存档是一个整体对象，避免棋盘和分数分开写导致状态不一致。存档格式以后变更时应增加版本处理。
