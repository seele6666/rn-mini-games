# Implementation Note: 1.1 Expo 工程基础

**Task:** 1.1 in ../tasks.md

## Requirement and dependencies

对应 `../specs/android-installation/spec.md` 的“提供可安装 APK”和 `../specs/game-catalog/spec.md` 的“启动进入小游戏首页”。无前置任务。项目根目录当前非空且无 Git 仓库；保留现有工作流文件。

## Files and interfaces

- 新增或合并根目录 `package.json`、`package-lock.json`、`app.json`、`tsconfig.json`、`assets/`、`src/app/` 和 Expo 所需配置；保留现有 `README.md`、`AGENTS.md`、`.agents/`、`.codex/`、`openspec/`。
- 在 `package.json` 中加入非交互测试脚本，例如 `"test": "jest"`，并设置 `jest-expo` preset；此任务只配置测试运行器。
- 若模板自带示例页面或底部栏，仅保留下一任务会用到的最小根布局与首页占位。

## Steps

1. 在项目内部临时目录运行 `npx create-expo-app@latest <temporary-name> --template default --no-agents-md --no-install`；先核对模板实际文件，合并到当前根目录，不覆盖已有配置和 OpenSpec 内容。清理临时目录前核对其绝对路径属于本项目。
2. 在根目录运行 `npm install`，再按 Expo 当前版本安装 `jest-expo`、`jest`、`@types/jest` 作为开发依赖；配置 `tsconfig.json` 类型和 Jest preset。
3. 初始化 Git（若仍无仓库），确认 `.gitignore` 排除 `node_modules` 与生成目录，保留 OpenSpec 文件。

## Verification

运行 `npm install`、`npx tsc --noEmit`、`npm test -- --runInBand --passWithNoTests`；预期均退出 0。确认原有 `openspec/config.yaml` 与 `.agents/skills/openspec-propose/SKILL.md` 仍存在，且 `npx expo start` 可启动开发服务。

## Risks or handoff notes

默认模板具体文件会随 Expo 版本变化。先检查生成文件，再按上面的职责合并，不能用覆盖整个根目录的操作。
