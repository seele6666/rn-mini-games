# Implementation Note: 2.3 困难档有限采样模拟

**Task:** 2.3 in ../tasks.md

## Requirement and dependencies

依赖：2.2。对应 [doudizhu-opponents](../specs/doudizhu-opponents/spec.md) 的“三档真实策略差异”“玩家视角信息隔离”“受限计算与合法回退”，覆盖“困难档开展推演”“搜索耗尽或失败”“思考期间离开或重开”。

## Files and interfaces

新建 `src/features/doudizhu/ai/search.ts`、`search.test.ts`。搜索输入为观察、随机源、注入时钟、节点／时间预算及取消信号；异步返回合法动作和采样数、节点、耗时等诊断。模拟用引擎处理样本状态，每名模拟策略仍只读自己的观察。

## Steps

1. 先测试预算0时合法回退、领出不能不出、取消及隐藏分配置换不变决定。
2. 根据自牌、公开历史、余牌数和已知地主底牌构造可能分配，正确处理已经打出的底牌，不把不出当能力缺失证据。
3. 以普通策略筛有限候选；为各候选模拟阵营胜负或截断估值，保留当前最佳合法动作。
4. 将生成、评分、采样、模拟均计入整体预算；采用设计起始参数400节点／150ms，约8ms片段后让出JS线程，所有循环可取消。
5. 初始合法回退需要廉价且有界；不得先无限计算普通评分再启动预算。搜索错误在仍有效的回合回退，取消只返回取消状态，由会话禁止提交。

## Verification

执行 `npm test -- --runInBand src/features/doudizhu/ai/search.test.ts`。在多候选场景诊断证明存在采样与模拟；可控时钟、节点及取消测试在预算内终止；模拟AI不见其他座位归属；回退全部合法。固定时钟／种子／预算结果可复现。

## Risks or handoff notes

增加预算不保证更强。固定节点测试不是手机性能测试；质量对照与真机耗时分别在5.1、5.3。不能把长同步循环装进一个定时器就称为分片。
