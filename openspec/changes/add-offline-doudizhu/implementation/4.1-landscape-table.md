# Implementation Note: 4.1 牌桌与手牌交互

**Task:** 4.1 in ../tasks.md

## Requirement and dependencies

依赖：3.2。对应 [doudizhu-session](../specs/doudizhu-session/spec.md) 的“横屏牌桌与可操作手牌”“新局难度与确认重开”，场景“地主手牌与选牌”“行动权限”“取消或确认重开”“暂停思考”，以及电脑提示和阵营结果规格。

## Files and interfaces

新建 `src/features/doudizhu/GameScreen.tsx`、`GameScreen.test.tsx`、`Hand.tsx`、`Hand.test.tsx`。GameScreen调用会话hook；Hand以实体牌ID处理选中集合。复用 `src/theme.ts` 与既有安全区／手势设施，不把完整游戏状态渲染成对手手牌。

## Steps

1. 写新局难度、恢复、叫抢、真人出牌、电脑思考、finished各阶段组件测试。
2. 实现固定安全区牌桌，展示对手身份和余牌、公共底牌、近期动作和轮到者；底牌未公开时使用背面。
3. 手牌采用可访问的重叠排布与独立横向浏览，保证20张中每张可点击选中／取消；不要在外层使用可抢手势的整页滚动。
4. 阶段按钮按引擎权限启用；非法选择显示原因且保留对局；提示只选牌或提示不出，真人再确认。
5. 加入返回、存档反馈、难度选择和重开确认，结果只展示真人及阵营胜负。

## Verification

执行 `npm test -- --runInBand src/features/doudizhu/GameScreen.test.tsx src/features/doudizhu/Hand.test.tsx`。预期实体ID选择无串牌；非真人回合禁提交、领出禁不出；提示不提交；未公开牌不显示；取消重开无变化。尺寸和快速手势另在5.3真机验收。

## Risks or handoff notes

Jest不能证明真实触摸或横屏布局。组件的辅助标签用于测试与可访问性，不在普通玩家界面展示搜索节点、存档版本等实现细节。
