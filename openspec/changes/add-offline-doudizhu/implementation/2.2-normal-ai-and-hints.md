# Implementation Note: 2.2 普通策略与真人提示

**Task:** 2.2 in ../tasks.md

## Requirement and dependencies

依赖：2.1。对应 [doudizhu-opponents](../specs/doudizhu-opponents/spec.md) 的“三档真实策略差异”“合法提示由真人确认”，以及“农民配合”场景。

## Files and interfaces

修改 `src/features/doudizhu/ai/heuristic.ts`、`heuristic.test.ts`。普通策略返回合法动作及内部评分信息；提示通过同一玩家观察调用策略，但不接受游戏状态提交函数。

## Steps

1. 写立即获胜优先、减少拆开炸弹／对子／连续组合、对手余牌威胁的固定战术案例。
2. 根据行动顺序、阵营、最近出牌者与余牌数实现农民支持队友；自己能立即完成阵营胜利时不要机械让牌。
3. 实现估计剩余手数与控制牌代价的评分，给相同评分稳定选择次序；保持信息与随机源契约。
4. 提示接口返回建议实体牌或合法不出，不调用applyAction，不改revision和存档。
5. 按所选难度分派策略；困难出牌的策略实现交给2.3，普通可作为其合法回退。

## Verification

执行 `npm test -- --runInBand src/features/doudizhu/ai/heuristic.test.ts`。上述战术局面有明确预期，地主／两农民的阵营收益正确；提示前后游戏状态不变；不能用隐藏牌决定配合或威胁。

## Risks or handoff notes

此任务的固定战术通过不是整体胜率证明；对局对照在5.1。提示在真人确认前只改变选择状态，过时提示由3.2丢弃。
