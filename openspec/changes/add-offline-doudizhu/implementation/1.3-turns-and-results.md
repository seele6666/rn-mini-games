# Implementation Note: 1.3 合法出牌与阵营结果

**Task:** 1.3 in ../tasks.md

## Requirement and dependencies

依赖：1.2。对应 [classic-doudizhu](../specs/classic-doudizhu/spec.md) 的“合法回合与连续不出”“阵营胜负与结果终止”，覆盖“连续两次不出”“非法或过时操作”“农民队友出完”“地主出完及恢复结果”。

## Files and interfaces

修改 `src/features/doudizhu/engine.ts`、`types.ts`、`engine.test.ts`。`applyAction` 是状态转换的唯一入口；有效出牌记录实体ID和规范化牌型，拒绝返回原因及不变状态。

## Steps

1. 先写牌权、重复ID、错误目标、旧回合、领出不出的拒绝案例。
2. 实现出牌移除实体牌、公开历史、当前目标、最后出牌者、revision和下一个座位。
3. 实现不出计数；第二次连续不出清空目标并交给最后有效出牌者，后续不出计数归零。
4. 出牌后立即检测手牌空，按地主或农民阵营结束；真人结果按阵营归属计算，不要求真人自己出完。
5. 完成finished动作拒绝及固定种子的随机合法轨迹检查，确保手牌与已出牌始终守恒。

## Verification

执行 `npm test -- --runInBand src/features/doudizhu/engine.test.ts`。非法动作深比较执行前后状态一致；两次不出恢复领出；地主和任一农民出完均正确停止；finished不接受任何后续操作。合法轨迹没有重复／丢失实体牌。

## Risks or handoff notes

不得在结束后先推进电脑再显示结果。底牌成为地主手牌后，公开底牌只是展示注释，守恒统计不把它们再算一次。
