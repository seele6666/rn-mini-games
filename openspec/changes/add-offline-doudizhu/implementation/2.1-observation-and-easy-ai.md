# Implementation Note: 2.1 公平观察与简单电脑

**Task:** 2.1 in ../tasks.md

## Requirement and dependencies

依赖：1.3。对应 [doudizhu-opponents](../specs/doudizhu-opponents/spec.md) 的“两名本地电脑完成对局”“玩家视角信息隔离”，场景“离线叫抢与出牌”“同观察不同隐藏分配”“叫抢时底牌隐藏”。

## Files and interfaces

新建 `src/features/doudizhu/ai/observation.ts`、`observation.test.ts`、`heuristic.ts`、`heuristic.test.ts`，在 `types.ts` 定义独立 `PlayerObservation`。观察构建在引擎边界，决策函数只接受观察、合法动作和独立随机源。

## Steps

1. 定义可见字段白名单；叫抢阶段没有公开底牌，不把完整状态或对手手牌作为隐藏附加字段传给策略。
2. 构造两份只改变他人隐藏分配的状态，验证同玩家观察完全一致。
3. 实现基于自己的高牌与组合的叫／抢选择，以及简单的小牌、完整组合和适度随机出牌。
4. 领出至少返回一项合法非空动作；跟牌可不出；finished不选择动作。
5. 使用与发牌分开的策略随机源，验证切换难度不会改变相同发牌种子的牌分配。

## Verification

执行 `npm test -- --runInBand src/features/doudizhu/ai/observation.test.ts src/features/doudizhu/ai/heuristic.test.ts`。预期观察不泄露实际他人归属；同观察与随机种子下决定相同；所有输出通过引擎验证；底牌仅在公开后可见。

## Risks or handoff notes

全副牌减可见牌可得未知集合，不等于可使用实际所有人的手牌。不要把发牌RNG的内部状态传入AI，否则可能反推出隐藏牌。
