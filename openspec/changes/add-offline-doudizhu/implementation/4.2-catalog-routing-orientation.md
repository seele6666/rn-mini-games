## Steps

2. 增加斗地主路由适配，与2048一致处理有历史返回和无历史replace首页；把路由focus传入会话。
3. 在Stack显式设首页、2048为portrait，斗地主为landscape；app配置允许页面决定方向。核对实际安装版本的orientation选项类型。

5. 用路由测试验证返回和失焦暂停；记录方向配置变更将需要新原生APK才能验收。
