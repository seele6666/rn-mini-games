# Spec Delta

## MODIFIED Requirements

### Requirement: 启动进入小游戏首页

应用 SHALL 在正常启动后展示竖屏小游戏选择首页，提供 2048 和斗地主两个已实现游戏的独立入口。

#### Scenario: 首次打开应用

- **WHEN** 玩家打开应用
- **THEN** 首页展示 2048 和斗地主游戏入口，数量为 2
- **THEN** 首页不展示尚未实现的游戏为可玩入口
- **THEN** 首页保持竖屏，不因最近玩过斗地主而停留在横屏

## ADDED Requirements

### Requirement: 进入和离开斗地主

玩家 SHALL 能从首页进入横屏斗地主，并通过页面返回操作或 Android 系统返回回到竖屏首页。再次进入 SHALL 按斗地主会话规格恢复已保存对局；原有 2048 进入、返回和恢复行为 SHALL 保持有效。

#### Scenario: 进入斗地主并返回

- **WHEN** 玩家选择斗地主，然后使用页面返回或系统返回
- **THEN** 先进入横屏斗地主，再回到竖屏首页
- **THEN** 返回后不继续运行离开页面的电脑回合

#### Scenario: 斗地主之后打开 2048

- **WHEN** 玩家退出斗地主后从首页进入 2048
- **THEN** 2048 为竖屏并恢复自己的棋盘、分数和胜利提示状态

#### Scenario: 缺少导航历史

- **WHEN** 玩家直接打开斗地主路由，导航栈没有可返回的首页
- **THEN** 返回操作仍能进入竖屏小游戏首页
