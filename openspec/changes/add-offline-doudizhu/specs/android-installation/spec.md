# Spec Delta

## MODIFIED Requirements

### Requirement: 独立运行核心游戏

已安装的 APK SHALL 无需 Expo Go 或开发服务器即可打开首页、游玩 2048 和完全本地的斗地主并使用各自存档。斗地主 SHALL 在 Android APK 中以横屏游玩；首页和 2048 为竖屏，返回及前后台切换后仍符合所在页面方向。

#### Scenario: 手机离线运行

- **WHEN** 玩家在 Android 手机上安装 APK，并断开开发服务器与网络
- **THEN** 可以打开首页、进入 2048、完成滑动和计分
- **THEN** 关闭后再打开仍能恢复保存的棋盘

#### Scenario: 四档斗地主离线运行

- **WHEN** 手机断网且没有 Expo Go 或开发服务器，玩家分别选择简单、普通、困难和非常困难的新斗地主对局
- **THEN** 简单、普通、困难、非常困难四档均可完成叫抢、电脑出牌和阵营胜负，不请求外部游戏服务或下载模型
- **THEN** 已保存的叫抢或出牌中对局在关闭重开后可以恢复

#### Scenario: 原生方向与后台恢复

- **WHEN** 玩家在首页、斗地主、首页和 2048 之间切换，并在斗地主中切后台再回来
- **THEN** 首页与 2048 为竖屏，斗地主为横屏，安全区域不遮挡主要操作
- **THEN** 系统自动旋转关闭时页面方向仍正确，后台恢复不会产生重复电脑动作
