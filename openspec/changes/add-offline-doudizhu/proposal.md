# Proposal

## Why

现有小游戏合集仅有 2048。用户希望加入可以自己离线游玩的基础三人斗地主，并通过可选难度的电脑对手获得不同挑战，同时继续学习 React Native。

## What Changes

- 2026-10-22升级：完整展示全桌最近三手出牌，新增约一秒公平离线expert难度；加入离线替代配乐、独立音乐/音量/震动设置及视觉轻震动反馈。原APK与基准记录保留，重新验证并本地交付1.2.0/code4 ARM64 APK。

- 首页提供 2048 和斗地主两个可玩入口，进入斗地主后展示横屏牌桌，返回首页或进入 2048 时为竖屏。
- 新增一名真人、两名电脑的 54 张牌斗地主：叫地主／抢地主、完整常见牌型、轮流出牌和阵营胜负；真人可当地主或农民。
- 提供简单、普通、困难、非常困难四档本地电脑策略；困难与非常困难使用有预算的未知牌采样与模拟，各档只使用所属玩家可见的信息。
- 提供选牌、提示、出牌、不出和确认重开；真人没有操作倒计时。难度在新局确定，恢复保留当前难度。
- 自动保存叫抢和出牌中的对局，退出、切后台、重启后可以继续；结算后的对局保持结果，下一局由用户明确开始。
- 首版只显示地主／农民胜负。具体叫抢轮次、带牌边界采用 brainstorm 中列出的固定版本，并在规格中给出可测试定义。
- 新 APK 需要在断网且没有开发服务器的条件下验证两个游戏、页面方向切换与各自存档。

## Capabilities

### New Capabilities

- `classic-doudizhu`：发牌、叫抢、牌型比较、合法回合、阵营胜负。
- `doudizhu-opponents`：两名本地电脑、可选难度、公平观察、受限推演与合法提示。
- `doudizhu-session`：横屏交互、对局恢复、生命周期处理、难度与重开。

### Modified Capabilities

- `game-catalog`：首页展示两个可玩游戏，并提供斗地主进入与返回。
- `android-installation`：独立 APK 离线游玩与保存覆盖两个游戏，并验收横竖屏切换。

## Impact

- 新游戏规划目标目录为 `src/features/doudizhu/`，新增路由 `src/app/games/doudizhu.tsx`；修改首页、根 Stack 的页面选项及 Android 方向配置。
- 使用已有 TypeScript、Expo Router、AsyncStorage、RN 手势及测试设施；优先使用现有 native stack 的页面方向选项，不预设新增模型或原生推理依赖。
- 斗地主拥有独立版本化存档。已有 `classic-2048`、`saved-game` 正式行为和 `game2048.save.v1` 格式保持兼容。
- 新增规则、机器人、存档、会话和界面测试，以及独立 APK 真机验收记录。困难档运行预算和实际牌力需量化验证。
- 无服务端或外部游戏 API。规划阶段只创建本变更的文档，不修改正式规格或产品代码；正式规格在实施验收后的同步／归档阶段更新。
