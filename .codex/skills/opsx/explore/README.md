# Explore：探索

使用 `openspec-explore`，讨论目标、约束和可选方案。

[阅读完整技能](../../../../.agents/skills/openspec-explore/SKILL.md)

此阶段不实现游戏代码。具体行为以链接中的技能为准。

Explore 本身不保证保存 `brainstorm.md`。如果要跨对话保留探索结论，请明确提出“把这次探索保存到一个 OpenSpec 变更的 brainstorm.md”，由 OpenSpec 创建变更并按当前 schema 写入；后续 Propose 继续使用同一变更。若直接进入 Propose，它会根据当前可见的讨论生成 `brainstorm.md`。
