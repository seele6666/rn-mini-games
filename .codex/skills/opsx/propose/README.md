# Propose：提案

使用 `openspec-propose`，按项目自定义 schema 为明确的变更生成探索结论、提案、规格、设计、任务清单和逐任务实施说明。

[阅读完整技能](../../../../.agents/skills/openspec-propose/SKILL.md)

变更文件位于 `openspec/changes/<change-name>/`；模板在 [`openspec/schemas/rn-2048-workflow/templates/`](../../../../openspec/schemas/rn-2048-workflow/templates/) 中。本次不预造游戏需求。
