# Superpowers 技能入口

本项目使用 Codex 已安装的 Superpowers 插件。本目录用于整理入口，不复制插件技能，避免更新后出现多份不同版本。

实际技能位置由 Codex 当前会话的技能列表提供。当前安装版本为 6.4.2；更换电脑时需在 Codex 中安装该插件。

常用技能：

- `superpowers:brainstorming`：澄清需求和讨论设计。
- `superpowers:writing-plans`：编写实施计划。
- `superpowers:test-driven-development`：测试驱动开发。
- `superpowers:systematic-debugging`：调查和定位问题。
- `superpowers:requesting-code-review`：代码审查。
- `superpowers:verification-before-completion`：完成前验证。

OpenSpec 负责项目变更文档；按当前任务需要结合上述技能使用。具体游戏工作流程稍后确认。
