# 记忆条目模板

新增、迁移或替代条目时使用。先检查两个记忆文件中已有的编号，沿用同一条目的编号；新增取下一个未使用的 `M-001` 形式编号。

```markdown
## M-<编号>：<简短标题>

- 规则：<一个可执行的用户要求，不扩大原话含义>
- 适用范围：<本项目全部对话／代码注释／某类任务等>
- 状态：候选／有效／已替代
- 来源：
  - <YYYY-MM-DD，能区分的用户轮次>：“<必要的用户原话>”
  - <重复偏好晋升时保留第二个不同轮次来源>
- 出现次数：<真实用户来源轮次数；明确长期要求可为1>
- 替代关系：<仅在发生替代时填写旧／新编号>
```

平台消息标识可用时作为轮次定位；不可用时使用真实的对话内位置说明，不伪造标识。用户引用、助手复述和代理描述不能增加次数。

写入位置与收尾：

1. 单次隐含偏好写入 `memory/candidates.md`；明确长期要求写入 `memory/preferences.md`。
2. 两个不同轮次的同范围偏好晋升时，将完整条目迁移至偏好文件，保留编号和来源，删除候选副本。
3. 长期规则发生替代时保留旧记录并改状态，关联新有效条目；处理与旧要求相关的候选。
4. 更新 `memory/index.md` 的有效规则索引，已替代规则不再列为有效。索引保持约30行，并能找到各范围的适用规则。
5. 向用户简短说明新增或调整的编号。只读、规划或写入受阻时，说明待沉淀内容与未落盘状态。

例：“这次回答简短”即使在两个用户轮次出现，也只对相应任务适用，不产生长期条目。这里的例子不写入真实记忆。
